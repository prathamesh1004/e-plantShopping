# Paradise Nursery 🌱

Paradise Nursery is a React-based plant shop web application where users can browse houseplants and add them to a shopping cart.

## Features

* Home page with Paradise Nursery introduction
* About Us section with company information
* Plant product listing page
* Product images, names, and prices
* Add plants to the shopping cart
* View items in the cart
* Remove plants from the cart
* Navigation between Home, Plants, and Cart pages
* Redux Toolkit for cart state management
* React Router for page navigation

## Technologies Used

* React
* Vite
* React Router
* Redux Toolkit
* React Redux
* CSS
* JavaScript

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Install the required dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.

## Application Flow

Home → Plants → Add to Cart → Cart → Remove from Cart
